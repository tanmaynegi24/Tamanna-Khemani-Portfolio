Tamanna Khemani — Marketing Portfolio

Extract this ZIP into a folder.
Open index.html in your browser to view the portfolio.

For a local server, run this from the extracted folder:
  python3 -m http.server 4173
Then open http://localhost:4173

To publish, upload the folder contents to a static website host.
Keep the assets folder alongside index.html, style.css and script.js.

Includes portfolio images, the original PetPulse pitch deck and résumé.
